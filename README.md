# E-commerce Recommendation System

## Project Overview

This project combines Data Mining, Graph Analysis, and Deep Learning techniques to build an intelligent product recommendation system.

The system analyzes product transactions and customer reviews to discover purchasing patterns, rank important products, and generate personalized recommendations.

---

## Project Objectives

- Discover frequently purchased product combinations.
- Rank products using graph-based algorithms.
- Analyze customer reviews using BERT.
- Build a recommendation engine.
- Provide an interactive GUI for users.
